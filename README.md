# Quiz Mania Mobile

Quiz de conhecimentos gerais com 10 perguntas por rodada.

## Recursos

- níveis fácil, médio e difícil;
- seleção de temas;
- 102 perguntas;
- ciclos sem repetição;
- pontuação e recordes;
- temas de conhecimentos gerais, entretenimento, internet, atualidades e curiosidades;
- layout adaptado para celular e computador.

## Executar

Abra o arquivo `index.html` em qualquer navegador.
